How it works

  • Once per UTC day, an Agent ID holder checks in by answering the day's scenario: Sign or Reject.
  • The contract checks the wallet holds an Agent ID. Miss a day and your streak restarts at 1.
  • The board ranks players by total days checked in, then best streak. It shows wallet addresses only.
  • Agent IDs are non-transferable and one per user, which makes it sybil-resistant, not sybil-proof.

Permissions

The contract has no owner and no admin function. It holds no funds, takes no BNB, charges no fees and cannot be paused or changed. You pay only network gas.

Agent Mode

The copied prompt makes your agent decide first, explain, then ask for your confirmation. It never signs on its own or on a schedule.
