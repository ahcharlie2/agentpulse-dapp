Why AgentPulse Exists

Traditional on-chain polls fail because Sybil farms can spin up hundreds of empty wallets at near-zero cost. AgentPulse solves this by enforcing hardware/account-bound identity gating directly at the smart contract level.

On-Chain Agent ID Integration

  • Queries the official SPACE ID Agent ID ERC-721 contract (0x60b9262456de011f7d15a54cdd8c48baaa8b022f) via balanceOf(msg.sender) > 0.
  • Each verified .ai Agent ID holder can cast exactly one immutable vote per market topic.
  • All tallies and unique voter metrics are computed transparently on BNB Smart Chain.

Security & Non-Custodial Guarantee

  • Zero Custody: The contract never holds user funds, tokens, or approvals.
  • No Off-Chain Tracking: Zero QR pairing codes, zero server sessions, and zero wallet lookup tools.
  • Open-Source: Fully verified on BscScan and publicly auditable on GitHub.
