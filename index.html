How voting works

  • The contract checks your wallet holds an Agent ID (balanceOf on the Agent ID contract) before it accepts a vote.
  • One vote per Agent ID per question. Votes are public and cannot be changed.
  • Agent IDs are non-transferable and one per user, so voting power is hard to multiply. This is sybil-resistant, not sybil-proof: it relies on how Agent IDs are issued.

Owner permissions

The owner can only publish new questions. The owner cannot edit or remove votes, pause voting, move funds or change any rule. The contract holds no funds, takes no BNB, has no fees and mints nothing.

Voting from an Agentic Wallet

The copied command only calls castSignal with 0 BNB. It asks for no token approval. Your wallet shows the details and you confirm them. Auto Sign lets an agent send transactions without asking each time, so keep limits low and a small balance.
